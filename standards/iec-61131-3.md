# IEC 61131-3 Foundation

IEC 61131-3 provides the conceptual foundation for programmable controller programming. This document is deliberately vendor-neutral.

## Languages

- Ladder Diagram (LD)
- Structured Text (ST)
- Function Block Diagram (FBD)
- Sequential Function Chart (SFC)

## Program concepts

- Programs
- Functions
- Function blocks
- Variables
- Data types
- Tasks
- Execution order

## Important limitation

IEC concepts do not guarantee identical syntax, libraries, instructions, memory models, timer implementations or compiler behavior across vendors. Vendor documentation for the selected platform takes precedence.

## Engineering principle

Use the IEC model to reason about control logic, then implement the actual solution using the target PLC's supported language, libraries and execution model.
